Normal Working Day – Operator Flow

Xplolog Mobile App Operator Journey

1 Start of Shift (Morning)

Operator Action

  • Open Xplolog app
  • Press ✅ Start Shift

App Prompts (Minimal & Fast)

  • Odometer reading (pre-filled with last known value, adjust if needed)
  • No downtime, no reasons, no extra questions

System Captures Automatically

  • Shift start timestamp
  • Operator ID
  • MMU ID
  • Initial odometer
  • ✅ Android GPS location (lat/long) - automatic & invisible
Important: Location capture is automatic and invisible. Do NOT ask operator to "confirm location".
↓
2 Driving Between Mines / Blast Areas

Operator Does NOTHING in App

  • Drives to different mines
  • Moves between blast sites
  • Parks, waits, queues

App Behavior (Passive)

  • Captures GPS points (low frequency, battery safe)
  • No "travel" button
  • No manual status changes
Operator mindset: "Driving is just part of the job. I don't have to log it."
↓
3 Pumping Explosives (Core Work)

Operator Action

  • Press ▶️ Start Pumping
  • Press ⏹️ Stop Pumping
  • Quantity is logged automatically

System Behavior

  • Pump start/stop timestamps already exist ✔
  • Pumping = MMU is operational
  • GPS location stored at pump start/stop
Key: No changes to operator behaviour - crucial for adoption.
↓
4 Normal Pauses During the Day

Examples

  • Waiting for blast clearance
  • Waiting for geology or QA
  • Lunch
  • Short delays

Operator Does NOTHING

  • Not downtime events
  • Remain: Operational but not pumping
  • Still count as available time
Benefit: Avoids over-reporting and confusion.
↓
5 Breakdown or Environmental Issue

Trigger (Something Abnormal)

  • MMU breaks
  • Lightning / heavy rain stops work

Operator Action

  • Press ⚠️ Report Downtime

Downtime Flow (Very Short)

  • Select type: 🔧 MMU Breakdown or 🌧️ Environmental
  • Select reason from list ("Other" requires comment)
  • Confirm odometer (pre-filled, adjust if needed)
  • Press ✅ Submit

System Behavior

  • Timestamp captured
  • MMU marked Non Operational
  • GPS location captured at downtime start
  • Pump actions disabled
Operator mindset: "Something is wrong → I report it → I carry on dealing with the problem."
↓
6 During Downtime

Operator Activities

  • Fixes the MMU
  • Waits for weather to clear
  • Moves to safer area (GPS shows this)

App Display

  • Clear banner: 🔴 MMU DOWN – [Reason] – 00:42 elapsed
  • Button shown: ✅ Resume Operation
↓
7 Resuming Work

Operator Action

  • Press ✅ Resume Operation
  • Confirm odometer reading (pre-filled)
  • Press ✅ Submit

System Behavior

  • Downtime closed
  • MMU back to operational
  • Downtime duration calculated automatically
↓
8 End of Shift

Operator Action

  • At end of day, press 🟥 End Shift

App Prompts

  • Final odometer reading (pre-filled)
  • (Optional) shift comment
  • Press ✅ Submit

System Captures

  • Shift end timestamp
  • Final odometer
  • GPS location
  • Shift summary locked
