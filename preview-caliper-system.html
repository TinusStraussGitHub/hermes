To process files with the working Python code (Calipering Reader.py):

  1. Place your .las files in a folder.
  2. Select the folder + the Excel template (Borehole Calipering Template.xlsx).
  3. Enter Information sheet details (Client, Mine, Block ID, etc.).
  4. The script writes sorted data, inserts formulas, deletes unused sheets/charts, and saves the result.
