Step-by-Step Flow Explanation

  1. 1. Initial Request - The BLASTMAP App or External Partner sends a credential & x-site-name request to the XPLOLOG Gateway.
  2. 2. Authentication - The Gateway forwards to Firebase to verify the target and generate a secure token.
  3. 3. Token Return - Firebase validates credentials and returns the token to the Gateway.
  4. 4. Target URL Delivery - The Gateway sends the target URL and token back to the client.
  5. 5. Direct API Call - For high-volume traffic, the client bypasses the Gateway and makes direct calls to Firebase APIs using the stored base URL and token.

This architecture ensures secure credential validation while enabling high-performance direct operations when needed.

Security Assurance

  • • OAuth 2.0 + PKCE authentication flow
  • • JWT token validation with PKCE
  • • 401 error handling for invalid targets
  • • Token expiration and refresh mechanism
  • • Audit logging for all API operations
